# 投注记录与自动验奖实现计划

**目标：** 保存、分页列出、删除投注，通过外部任务拉取官方开奖并逐期验奖。

**架构：** Node.js 内置 HTTP 服务 → 投注/验奖服务 → SQLite Repository。官方开奖适配器独立，前端继续使用静态 HTML/CSS/JS，通过同源 `/api` 通信。新增服务要求 Node.js 22.13+，现有 CLI 与离线选号继续可用。

**约束（按后续需求更新）：** 页面和投注接口直接访问，仅验奖任务使用单独配置的任务令牌，不写入代码。新投注保存投注时间和连续期数，按照实际销售截止时刻筛选真实历史开奖，逐期绑定，不预测期号；旧记录继续兼容明确期号。服务器验证号码并重新计算投注金额。复式用组合数计算各奖级中奖注数；大乐透按 26014 期切换规则，仅一二等奖追加。奖金以官方单注奖金为准，缺失时保留待补全状态，不能记为零；特别派奖与税后金额不计算。

**文件：** `server/domain.js` 输入与验奖；`server/repository.js` SQLite 建表和事务；`server/draw-provider.js` 官方数据适配；`server/service.js` 用例；`server/app.js` 路由与鉴权；`server/index.js` 启动；`lottery/records.js` 列表与新增删除界面；`server/*.test.js` 行为测试；`server/README.md` API、部署和任务调用说明。

## 重点复查

跨年按实际日期匹配，不通过期号加一预测；未来开奖保持待匹配；已生成号码与正在修改的设置不能混用；重复任务不得重复累计奖金；上游缺页、缺期、首期缺口、奖金缺失、数据库重启不能导致错位或丢失投注；验奖任务必须校验任务令牌。
