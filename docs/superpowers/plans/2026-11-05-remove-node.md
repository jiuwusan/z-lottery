# 移除 Node.js 依赖

用户要求：CLI 与测试迁移到 Go，删除 package.json、旧脚本及 CI、文档中的相关配置。直接在当前分支执行。

方案：保留浏览器原生 JavaScript；用纯 Go 的 goja 在 Go 测试中执行真实浏览器选号源码。新增 cmd/lottery，与服务共用 internal/lottery 的配置、号码和规则。开发、测试和生产均不需要 Node.js。
