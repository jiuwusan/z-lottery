# 添加到桌面

在现有页头增加“添加到桌面”按钮，服务电脑和手机。继续使用原生 HTML/CSS/JavaScript 与 Go embed，不新增运行依赖、分支，不提交或部署。

## 方案

- 采用 PWA manifest、192/512 PNG 图标、180 PNG Apple touch icon 和独立窗口启动配置。图标由现有 favicon.svg 等比例栅格化，保持品牌一致。
- 支持 beforeinstallprompt 的浏览器在用户点击时调用原生安装；其他浏览器展示适合当前设备的手动说明。相比仅提供操作说明，此方案在支持的浏览器里可以直接安装；原生安装包需要额外平台构建和分发，不适合本次网页功能。
- iPhone/iPad 提示分享菜单添加到主屏幕，macOS Safari 提示添加到程序坞；安卓及电脑其他浏览器提示安装菜单。微信等内置浏览器先提示使用系统浏览器。
- 普通 HTTP 和 file 页面说明需要 HTTPS/本机开发地址；仍可关闭指引继续使用。安装不能绕过系统确认。
- 已在独立应用窗口运行或收到 appinstalled 时隐藏入口；取消、错误和未收到安装事件均不宣称安装成功，不持久化“已安装”标记。
- manifest 的 start_url、scope、图标以及页面链接使用相对路径；省略 id，使应用身份默认采用实际启动地址，避免同源子目录间的身份冲突，兼容反向代理剥离前缀的子目录部署。
- 本次只增加安装能力，不引入 service worker/离线缓存，保持投注接口和现有资源更新语义。现代浏览器安装不要求 service worker，记录功能继续需要联网。

## 验收

实际嵌入资源可通过 GET/HEAD 获取，manifest MIME 正确，图标尺寸正确，未开放其他文件。安装状态、重复点击、取消和失败、手机/桌面指引有自动回归；浏览器检查桌面与窄屏布局、弹窗关闭和焦点恢复；运行完整 Go 质量入口。真实手机和系统级安装无法用桌面模拟证明，交付说明实际验证边界。
