# 静态号码生成页面

整个 `lottery` 目录可以直接部署，包含 `index.html`、`styles.css`、`lottery-core.js`、`app.js` 和 `records.js`。离线选号不需要 Node.js、安装依赖、构建、后端接口或外部 CDN，也可以双击 `index.html` 本地使用。投注持久化和自动验奖需要后端服务。

支持大乐透与双色球、单式/复式、多组、共享号码、倍数、连续期数和大乐透追加。默认值与项目根目录的 `lottery.js` 一致。页面打开时不自动生成，点击「生成号码」后才显示号码和金额并启用复制。恢复默认设置只重置参数，不生成号码。切换彩种会恢复该彩种的选号数量并清空共享数量；切换至双色球时取消追加。修改设置后，点击生成才更新号码和金额，复制的也是已生成结果。

浏览器使用 `crypto.getRandomValues` 和拒绝采样生成均匀随机数。共享号码是最低交集；其他位置也可能偶然重复，各组分别计费。页面每次最多生成 1,000 组，超出 JavaScript 安全整数精度的金额会被拒绝。不提供预测或购买功能；验奖由连接的后端服务提供。

选号区域数值设置使用「− / ＋」步进器，每次调整 1，无需键盘输入。达到上下限时对应按钮禁用；减少选号数量时，共享数量同步限制在选号数量以内。调整参数不会自动生成号码。

“新增投注”直接使用随机选号表单：配置参数 → 生成号码 → 保存投注。连续期数为 1～100，保存已展示的同一批号码、倍数、追加状态和期数。可填写实际投注时间（北京时间），留空使用服务端保存时刻；不能填写未来时间。保存不依赖官方开奖接口，也不提前锁定预测期号。

验奖任务按日期升序获取历史开奖，只有投注时间早于当期销售截止时间才计入，选取最早的连续 N 次实际开奖。截止时刻及其后的投注从下一期开始；休市、临时调整及跨年跟随真实记录。开奖不足时保留待匹配位置，已匹配期号和结果持久保存。修改设置后重新生成才能保存，同一次生成保存后禁用保存按钮。

## Nginx 部署

以上为离线选号模式。页面新增“投注记录”管理区，需要运行 Node.js 后端并转发同源 `/api/`，配置见 [服务部署说明](../server/README.md)。静态部署时仍可正常选号和复制，记录功能需连接服务。

例如，将此目录的全部内容复制到 `/var/www/z-lottery/`，使用以下配置（替换域名）：

```nginx
server {
    listen 80;
    server_name lottery.example.com;
    root /var/www/z-lottery;
    index index.html;

    charset utf-8;

    location / {
        try_files $uri $uri/ =404;
    }
}
```

确保 Nginx 的 `http` 配置中包含 `include mime.types;`，然后运行 `nginx -t` 并重载 Nginx。

也可以复制到现有站点根目录下的 `lottery/` 文件夹，通过 `/lottery/` 访问。页面所有资源都使用相对路径，无需修改代码或配置前端路由回退。

复制结果包含彩种、选号规格、倍数、期数和各组号码，追加投注时倍数显示为“1倍追加”等文案，不包含共享数量、注数或金额。号码按两位数字显示，以空格分隔，各组之间留一个空行。复制按钮优先使用安全上下文的 Clipboard API，普通 HTTP 或本地文件尝试浏览器的兼容复制方式；若浏览器禁止复制，会提示手动选择复制。
